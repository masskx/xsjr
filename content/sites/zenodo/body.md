## 解决什么问题

论文里的自建数据集，常常审稿时要得到、见刊后就找不到；塞进补充材料又受体量和格式限制。Zenodo 给每次上传分配一个 DOI 和固定版本号，让数据集、代码与实验脚本变成可被引用、可长期访问的正式科研产出。

## 主要能力

- 免费上传数据集、软件、图表、报告等多种类型，每条记录自动获得可引用的 DOI，可直接写进参考文献。
- 版本管理：更新数据会生成新版本，旧版本仍可访问，引用时可指定具体版本号。
- 提供开放、受限、禁运等访问级别，需要同行评审期保护或只对特定人员开放的数据可以设条件。
- 支持关联 GitHub 仓库自动归档发版，也提供 REST API 与 OAI-PMH 供批量取元数据。
- 可按 community（期刊、项目、机构）组织收录，便于按领域浏览与检索。

## 适合谁用

适合需要给论文数据找一个长期存放与可引用方式的研究者，以及做可复现研究、要把代码和数据一并归档的课题组。

## 使用提示

- 上传前先看清目标期刊的数据政策，多数期刊要求在正文给出数据集 DOI，而不是只贴一个仓库链接。
- 单条记录有体量上限（具体数值以官方帮助页为准），大文件先压缩或拆分；务必附 README 说明字段含义与生成脚本，否则别人拿到也用不了。
- 公开记录下载不需要登录，上传和建 community 需注册（支持 ORCID 等账号）；中国大陆访问一般正常，下载大文件建议用命令行工具断点续传。
