## 解决什么问题

期刊投稿周期动辄半年，等正式见刊再读就已经落后了。arXiv 让研究者在提交当天就拿到物理、数学、计算机、统计等领域的预印本全文，用来跟进最新方法、在评审前了解同行的早期结果，也方便在论文里说明某工作的版本演进。

## 主要能力

- 按学科分类逐个浏览每日新提交，比如 cs.CL、cs.LG、stat.ML 各有独立的 new / recent 列表，可以固定盯几个方向。
- 高级检索支持标题、作者、摘要、arXiv 编号、提交日期区间与分类组合过滤，适合定点找回某篇论文。
- 每篇论文提供 PDF、部分提供 HTML 版本、源码包（TeX 源文件）以及版本历史，能下载原始 LaTeX 复现排版或做文本分析。
- 支持邮件订阅与 RSS，按分类或检索式持续推送新论文，不用每天手动刷。
- 提供免费开放的元数据接口（arXiv API / OAI-PMH），可批量拉题录做文献计量或训练语料。

## 适合谁用

适合需要紧跟前沿的研究生和青年教师，尤其是计算机、物理、数学、统计方向；也适合要下载 LaTeX 源码、做综述或复现实验的人。

## 使用提示

- 找某个方向的最新进展，用分类页的 new 列表比首页关键词搜索准确得多；要精确检索请走高级检索页，并加上分类限定，否则同名跨学科论文会大量混入。
- arXiv 上的文章未经同行评审，结论与数字可能与最终发表版有出入。引用前最好核对期刊正式版，并在条目里注明所用版本与访问日期。
- 只读和下载不需要登录，提交论文才需要注册账号；中国大陆一般可直接打开，但 PDF 下载偶尔较慢，可以先取源码包或换时段重试。
