## 解决什么问题

AI 辅助写作之后，参考文献里混进虚构条目的概率显著上升。这些条目通常长得很像真的：作者是真实活跃的学者，期刊名正确，DOI 格式也合规——只有打开 doi.org 才会发现不存在。

人工逐条打开几十条引用很慢，但**格式与内部一致性检查可以批量做**：年份与卷期是否匹配、作者拼写是否与同组其他文献一致、DOI 前缀是否属于该出版社、标题风格是否异常。

## 安装

```bash
mkdir -p ~/.claude/skills/reference-verification
# 右侧 SKILL.md 完整内容 → ~/.claude/skills/reference-verification/SKILL.md
```

## 使用

```
用文献核验技能检查 references.bib，逐条给出可解析性判断
```

Skill 会输出一张表：条目 → 可疑等级 → 具体疑点 → 你要执行的核验动作。**它不会替你访问网络**，这一步必须你自己做。

## 判定逻辑

分三档：可解析（格式与内部一致性均无异常）、待核（存在 1 处异常，需打开 doi.org 确认）、高度可疑（存在 2 处及以上异常，或作者组合在领域内不存在）。
