## 解决什么问题

绝大多数投稿被退回修改的图表问题，都不是「图画得不好看」，而是**不满足印刷与可读性要求**：字号缩到印刷尺寸后看不见、红绿配色让色盲读者无法区分、误差棒没写清是标准差还是标准误、图注不完整导致图脱离正文就读不懂。

这些逐项都能机械检查，但人眼看自己的图时会自动补全。

## 安装

```bash
mkdir -p ~/.claude/skills/figure-quality-review
# 右侧 SKILL.md 完整内容 → ~/.claude/skills/figure-quality-review/SKILL.md
```

## 使用

两种方式都行：

1. **给代码**（推荐，能查得更细）：把你的 matplotlib 绘图脚本贴给它。
2. **给描述**：说明图类型、尺寸、字号、配色、是否有误差棒与图注。

```
用绘图自检技能检查这段 matplotlib 代码，目标期刊单栏宽 8.3 cm
```

## 判定依据

字号下限按**最终印刷尺寸**折算：正文 7 pt、坐标轴标签 8 pt、图例 7 pt。分辨率按期刊常见的 300 dpi（位图）/ 矢量优先。
