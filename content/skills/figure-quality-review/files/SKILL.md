# 科研绘图自检

## 前置判断

先确认你拿到的是什么：

- **绘图代码**（matplotlib / R ggplot2 / Origin 导出参数）：可以精确检查，优先走这条路径。
- **文字描述**：只能检查结构性项目，检查前先说清哪些项你无法验证。
- **图片本体**：你无法可靠读取像素与字号，明确告诉用户"我看不到图的细节，请提供代码或描述"，不要假装看过。

## 检查清单（逐项判定，通过/不通过/无法判断）

### A. 尺寸与分辨率
- 物理尺寸是否匹配目标期刊栏宽（单栏 8.3 cm / 双栏 17.1 cm 为常见值）？
- 位图是否 ≥300 dpi？矢量图是否避免嵌入位图？
- 字体是否嵌入或转曲（避免投稿系统替换字体导致错位）？

### B. 可读性
- 最终印刷尺寸下：正文 ≥7 pt、轴标签 ≥8 pt、图例 ≥7 pt？
- 线条粗细 ≥0.5 pt？标记点在印刷尺寸下是否还分得清？
- 是否有被裁掉的标签或重叠的文字？

### C. 配色与可及性
- 是否只靠红/绿区分类别（红绿色盲人群约 8% 男性）？
- 是否同时使用了色相 + 明度/形状/线型冗余编码？
- 灰度打印后是否仍能区分各组？
- 顺序型数据是否用了感知均匀的 colormap（viridis / cividis），而不是 jet？

### D. 数据表达完整性
- 误差棒是否在图注中说明是 SD / SE / 95% CI / 极差？
- 柱状图是否给出了散点或样本量 n？（仅有柱高无法判断分布）
- 是否用了截断的 y 轴放大差异而未标注？
- 对数轴是否明确标注？
- 箱线图是否说明了须的定义（1.5 IQR？最小最大值？）

### E. 坐标轴与单位
- 每个轴都有量名与单位？
- 单位符号是否符合 SI（µm 而非 um）？
- 刻度密度是否合适？是否有不必要的科学计数法？

### F. 图注（Caption）
- 图注是否自足——脱离正文也能读懂这张图在说什么？
- 是否说明了 n、统计方法、显著性标记含义（* p<0.05 具体到用了什么检验）？
- 多子图是否按 (a)(b)(c) 在正文与图注中一致引用？

## 输出格式

按优先级分三组，每组内一条一行：

```
[P0 必须改] D-误差棒：图注未说明是 SD 还是 SE → 补一句"Error bars denote ±1 SD (n=3)."
[P1 建议改] C-配色：两组仅用红/绿区分 → 增加实心/空心标记，或改用 Okabe-Ito 调色板
[P2 可选]   E-单位：X 轴写了 um → 改为 µm
```

无法判断的项单独列在「需要你确认」一节，写明需要什么信息才能判断。

## 硬性约束

- 不要评论"这张图不够美观"。只评论可验证的规范项。
- 不要臆造期刊的具体数值要求；不确定时写"请以目标期刊作者指南为准"。
- 如果用户只给了描述，明确声明本次检查是"基于描述"，遗漏项由用户自行补查。
