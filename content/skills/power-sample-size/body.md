## 解决什么问题

样本量估算之所以经常出错，几乎都错在输入端而不是计算端：效应量随手取了一个「中等效应」，α 与把握度不写，脱落率不加，多重比较不校正，最后算出来的数字看起来精确，实际上是个占位符。

更麻烦的是事后误用——实验做完发现不显著，回头算一个「事后功效 0.35」来论证「样本不够」。这种说法在方法学上是无效的，因为观测到的效应量本身受样本波动影响。

这个技能把估算拆成「设计 → 效应量口径 → 参数 → 计算 → 敏感性 → 报告」六步，每步都要求写清依据，并明确区分事前估算与事后检验的正当用法。

## 适用场景

- 写研究方案、开题报告或基金申请书，需要给出样本量及其依据
- 稿件被审稿人问「样本量是否充分」，需要补写方法与讨论
- 设计阶段想知道「在当前资源下能检出多大的效应」
- 需要判断已有的样本量估算是否合理（审稿场景）

## 使用说明

1. 先说明研究设计：几组、配对还是独立、主要结局的测量尺度、是否重复测量。
2. 给出效应量的来源：既往文献的具体数值、预实验数据、或最小临床意义差值。没有来源就必须先补文献，不要跳过。
3. 明确 α、把握度目标、单双侧、预期脱落率、是否校正多重比较。
4. 技能会给出公式与手算步骤，计算结果请用 R 的 pwr、G*Power 或 Python 的 statsmodels 复核一遍。

## 验收标准

输出必须包含：参数表（每个参数附来源）、所用公式与口径说明、一张效应量×样本量的敏感性网格、以及可直接粘贴的方法段与局限句。只给一个「需要 128 例」的数字视为不合格。
