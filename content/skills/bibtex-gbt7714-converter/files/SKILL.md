# 参考文献格式批量转换

## 立场

格式转换是**机械映射**，不是内容创作。因此三条铁律：

1. **缺失字段必须暴露**，不许用推测值、缩写或占位数字补齐；
2. **类型标识必须有依据**，[J]、[M]、[D] 不是凭感觉写的；
3. **每条转换结果都要能回到原始条目**，因此输出必须带原始键名。

## 工作流程

### 第一步：确认四项前提
- 源格式：BibTeX / biblatex / RIS / EndNote 导出文本 / 已排版参考文献
- 目标格式与版本：GB/T 7714 的具体版本与著录方式（顺序编码制或著者-出版年制）
- 语种处理：中文条目的英文译名是否保留、双语著录如何处理
- 输出形态：纯文本条目 / 可粘贴进 Word 的样式 / 仍是结构化的 bib 条目

判定口径：目标版本未明确时，先问；不允许「按最新版」这种默认——不同版本在电子资源与文献类型标识上细节不同。

### 第二步：字段映射
以 BibTeX 到 GB/T 7714 为例，核心对应关系：
- `author` → 主要责任者（中文三人以上加「等」，英文三人以上加「et al」；机构作者按原名）
- `title` → 题名（保留副题名的分隔符写法）
- `journal` → 期刊名（刊名写法以原刊为准，不做翻译改写）
- `year`/`volume`/`number`/`pages` → 年,卷(期):起止页
- `publisher`/`address` → 出版地:出版者（专著、会议录、学位论文需要）
- `booktitle` → 会议录名或文集名（会议论文需注明会议地点与时间时另加）
- `doi`/`url`/`urldate` → 电子资源必备项
- `type`（学位论文、报告等）→ 文献类型标识与载体标识

反向（GB/T 7714 → BibTeX）时，需注意「等」不能写进 `author` 字段，应还原为完整作者列表；无法还原时标注需人工补全。

### 第三步：类型标识判定
| 文献形态 | 类型标识（依据） |
| 期刊论文 | [J] |
| 专著/图书 | [M] |
| 学位论文 | [D] |
| 会议论文（收入文集） | [C] 或 [M]// 的析出文献写法，取决于著录规则 |
| 报告 | [R] |
| 标准 | [S] |
| 专利 | [P] |
| 电子公告/在线资源 | [EB/OL] |
| 报纸 | [N] |

要求：判定说明写在条目旁，不允许只给标识不给依据。同一篇文献在两种来源里被标成不同类型时，以原始出版形态为准。

### 第四步：缺失字段清单
列出每条缺失的必著录项：作者不全、无卷号、无期号、无起止页、无出版地、无 DOI。按影响分级：
- **致命**：作者或题名缺失，条目不可用
- **重要**：卷期页缺失，影响可查证性
- **次要**：DOI 或 URL 缺失，视目标刊要求而定

### 第五步：转换后校验
对每条转换结果检查五项：作者分隔与「等」的位置、标点全半角、卷期页括号格式、类型标识、条目末尾标点。检查结果以表格给出，不要只说「已检查」。

### 第六步：人工核对项
必须回原始数据库核对的内容：作者拼写与顺序、卷期页码、刊名缩写是否被要求展开、年份是否为在线优先年份还是正式出版年份、DOI 是否指向该文。

## 硬性约束

- 绝不编造卷号、期号、页码、DOI、出版地或作者姓名；缺失一律标 `[待补：…]`。
- 不把「等」写入 BibTeX 的 `author` 字段。
- 不跨版本混用规则：一次转换只用一个目标版本。
- 不保证翻译刊名或题名；如需英文著录，只做保留原文的处理，并提示需人工确认。
- 不从 PDF 里提取文献信息（那需要先做结构化整理）。

## 做不到什么

- 无法联网核对：DOI、卷期页码、作者拼写的正确性只能你回原库确认。
- 不处理版本细节裁量：GB/T 7714 各版本与各刊社的自定细则差异，需要你指定口径。
- 不做完整文献管理：不代替 Zotero/EndNote 的去重、合并与库维护。
- 大批量（数百条以上）转换时容易漏项，建议分批并逐批核对，不要一次性信任输出。
