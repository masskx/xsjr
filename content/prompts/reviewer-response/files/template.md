## 输出要求

对每一条意见，按以下四段写：

1. **意见摘要**——用审稿人自己的措辞概括，一句话，不加评价。
2. **我们的判断**——三选一：接受并修改 / 部分接受 / 礼貌澄清或反驳。说明依据是什么。
3. **具体行动**——改在稿件的哪一处，改了什么。若需补实验，写明实验设计与预计周期。
4. **回复正文**——可直接放进 response letter 的段落，语气遵循「{{tone}}」。

硬性约束：

- 不得编造未完成的实验、数据或文献。作者未提供对应修改时，写「我们将在修订稿中补充……」并留出占位。
- 反驳必须引用稿件中的具体位置（节号 / 图号 / 表号），不能只写「审稿人误解了」。
- 每条回复不超过 180 字，先结论后理由。
- 若多位审稿人意见冲突，单独加一节说明你如何兼顾，以及最终取舍的依据。

最后额外输出一节「**需要作者确认的事项**」，列出你无法判断、必须由作者本人决定的问题（例如是否愿意补实验、是否接受拆分稿件）。
