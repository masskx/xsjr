# 学位论文模板套用

把已写好的论文内容迁移到学校官方 Word 模板中：映射样式、处理图表公式与参考文献，避免格式审查返工。

## 工作流程

1. 确认学校、学位类型和模板版本；提醒用户以研究生院或教务处最新发布的模板为准。
2. 建立样式映射表：用户稿中的每种段落（各级标题、正文、图表题、公式、参考文献、附录）对应到模板的哪个样式。
3. 迁移方法：在模板中“选择性粘贴 → 只保留文本”，再套用模板样式；图片单独插入，表格保留结构后套表格样式。
4. 公式：统一使用公式编辑器或 MathType，按章编号（如 (3-2)），正文用交叉引用。
5. 参考文献：建议用 Zotero 或 EndNote 按学校要求的样式（多为 GB/T 7714-2015）重新生成。
6. 最后核对：目录、页码、页眉（奇偶页不同时尤其注意）、摘要与关键词、声明页、图表目录。

## 输出

样式映射表、迁移步骤、逐项核对清单。

## 注意事项

- 模板要求优先于通用规范。
- 提醒用户迁移前备份原稿。
- 不提供代写或修改论文实质内容的服务。
