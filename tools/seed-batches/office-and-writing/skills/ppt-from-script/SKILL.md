# 讲稿生成 PPT

根据讲稿或论文内容，生成逐页 PPT 大纲：每页标题、要点、配图建议与讲者备注，可直接在 PowerPoint 或 WPS 中制作。

## 工作流程

1. 确认时长和听众：按约每页 1–1.5 分钟估算页数；同行专家与外行听众的详略不同。
2. 定故事线：问题与背景 → 方法 → 关键结果（2–3 个） → 结论与意义 → 下一步/致谢。
3. 逐页写：一句结论式标题（不是“实验结果”，而是“方法 A 把误差降低了 18%”）+ 不超过 4 条要点。
4. 为每页给出配图建议：用论文中的哪张图、需要重画什么、示意图的构图。
5. 写讲者备注：这一页要说的话，控制在时长内。
6. 最后给出时间分配表。

## 输出

逐页 PPT 大纲（Markdown 表格或分节列表）+ 时间分配表。

## 注意事项

- 不编造论文中没有的数据或结论。
- 需要 HTML 演示稿时，可输出单文件 HTML，但默认给 PPT 大纲。
