# 答辩 PPT 结构

为本科、硕士、博士答辩设计 PPT 结构与页数，突出研究贡献，提前准备评委常问问题的备用页。

## 工作流程

1. 确认答辩类型（开题/中期/毕业）、时长和学校要求的必备内容。
2. 给出结构：研究背景与问题 → 研究现状与不足 → 研究内容与技术路线 → 主要结果 → 创新点 → 不足与展望。
3. 创新点单独成页，用 2–3 条可被验证的表述。
4. 列出评委常问问题（方法选择理由、对比实验是否公平、数据来源、局限性、工作量）并为每个问题准备一张备用页的要点。
5. 检查清单：学校/学院标识、导师署名、页码、字号可读性。

## 输出

答辩 PPT 页面结构表 + 备用页清单 + 预演问题清单。

## 注意事项

- 创新点必须与论文正文一致。
- 备用页放在致谢之后。
