# Excel 数据整理

把实验或问卷导出的 Excel 表格整理成规范的“整洁数据”：统一列名与单位、处理缺失值、去重、透视汇总，便于后续统计分析。

## 工作流程

1. 先看结构：每行是一个观测、每列是一个变量吗？合并单元格、多行表头、一格多值都要先拆开。
2. 统一列名（英文或拼音、无空格）和单位；日期统一为 YYYY-MM-DD。
3. 缺失值：区分“未测量”和“为 0”；用统一标记（空白或 NA），不要用 0 代替缺失。
4. 去重与校验：用“删除重复项”，用条件格式标出超出合理范围的值。
5. 汇总：用数据透视表按组统计均值、标准差、计数；给出对应的公式（AVERAGEIFS、COUNTIFS）。
6. 需要复现时，给出等价的 Python（pandas）或 R 代码。

## 输出

整理步骤 + 新的表结构说明 + 透视/公式 + 可选的 pandas 代码。

## 注意事项

- 原始数据另存一份只读副本。
- 不改动原始测量值，所有转换写在新列中。
