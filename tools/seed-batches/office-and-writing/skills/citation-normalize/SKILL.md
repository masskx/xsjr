# 引用规范化检查

检查论文中的引用是否规范：直接引用加引号、转述注明出处、自我引用与图表引用标注完整，减少因引用不当造成的重复与学术不端风险。

## 工作流程

1. 逐段识别：哪些是作者自己的观点，哪些来自文献（直接引用、转述、数据、图表）。
2. 直接引用：必须加引号并标注页码（按要求）。
3. 转述：用自己的话表达，并在句末标注出处。
4. 自我引用：引用自己已发表的成果同样需要标注，避免“自我抄袭”。
5. 图表：改编或转载他人图表需注明来源，必要时取得许可。
6. 输出问题清单：位置、问题类型、建议改法。

## 输出

引用问题清单（位置 / 类型 / 建议）与修改示例。

## 注意事项

- 只指出问题和改法，不替用户判断是否构成学术不端。
- 对不确定来源的表述，建议用户回查原文。
