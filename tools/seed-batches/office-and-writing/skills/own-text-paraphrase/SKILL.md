# 学术改写（降低文字重复）

在保持原意、数据与引用不变的前提下，改写你本人写作中与已有文献表述过于接近的段落，并规范引用，降低文字重复率。

## 工作流程

1. 先确认：段落是用户自己的写作或已正确引用的内容；改写的目标是用自己的话准确表达，而不是掩盖抄袭。
2. 保留不变的内容：专业术语、数据、公式、引用标注。
3. 改写方法：调整句式结构（主动/被动、长句拆分）、改变论述顺序、用自己的理解概括而不是同义词替换。
4. 需要原样使用他人表述时，改为直接引用并加引号与出处。
5. 逐段给出：原文 → 改写稿 → 修改说明（改了什么、为什么）。
6. 最后提醒用户通读一遍，确认改写后意思没有偏差。

## 输出

逐段对照表：原文、改写稿、修改说明；以及需要补充引用的位置。

## 注意事项

- 不得用于把他人成果改写成自己的成果；他人的观点和数据必须引用。
- 不承诺具体的查重率；以学校或期刊使用的系统结果为准。
- 改写后的专业表述需由作者本人核对。
