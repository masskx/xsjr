# 参考文献格式统一（GB/T 7714）

把参考文献列表统一为 GB/T 7714-2015 格式（顺序编码制或著者-出版年制），检查作者、刊名、卷期页码与 DOI 的缺漏。

## 工作流程

1. 确认使用顺序编码制还是著者-出版年制，以及学校或期刊的额外要求（是否保留 DOI、英文作者名大小写）。
2. 按文献类型套用格式：期刊 [J]、专著 [M]、论文集 [C]、学位论文 [D]、标准 [S]、专利 [P]、电子资源 [EB/OL]。
3. 检查每条：作者（超过 3 位写前 3 位加“等”/“et al.”）、题名、刊名、年、卷（期）、页码、DOI。
4. 标出缺失信息，不要自行补造；建议用户用 DOI 在 Crossref 或数据库中核对。
5. 输出格式化后的列表，并在最后附“待核对”清单。

## 输出

格式化后的参考文献列表 + 待核对清单。

## 注意事项

- 不编造缺失的卷期页码或 DOI。
- 正文引用编号要与列表顺序一致，提醒用户同步检查。
